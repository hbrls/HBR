# Scoring 拟合开发与模型选择

> updated_by: HBR - GPT-5
> updated_at: 2026-07-14 20:49:28

## 最终需求

Fingerprint 将通过比例 `x` 映射到 10 分制分数，硬约束如下：

- `0 <= S(x) <= 10`；
- `S(0)=0.001`、`S(0.6)=4`、`S(0.8)=6`；
- `S(1)>9.99`；
- 曲线连续、单调、全局定义，不允许分段；
- 视觉上只有一个主要转折过程；数学上允许最多两个不明显的曲率零点。

## 开发模式

当前 Agent 没有 Python 拟合环境，只负责模型分析和代码编写，不执行拟合脚本，也不猜测参数。

1. 当前 Agent 编写 `fit_*.py`，定义模型、约束、求解方法和质量门禁。
2. 具有 Python、NumPy、SciPy 环境的 Agent 执行拟合。
3. 执行方回传参数、预测值、逐点残差、形状诊断和 runtime。
4. 当前 Agent 审核结果后再更新后续使用方。

未经外部环境实际拟合的参数不得进入 runtime，也不得声称已经通过数值验证。

## 问题与结论

| 尝试 | 关键结果 | 结论 |
|---|---|---|
| 四锚点等权 Richards | `S(0)`被拟合为约 `0.647` | 总 RMS 不能替代逐点质量门禁 |
| 端点硬约束 Richards | 中间点出现约 `-2.67/+0.54` 误差 | 加权或增加次数不能弥补模型表达冲突 |
| 三锚点 Richards profile | 最优落在 `nu→0` 边界，`S(0.8)=6.5405`、`S(1)=8.2141` | 一维解析 profile 可区分算法失败与无根 |
| Chapman–Richards | 三锚点达到机器精度，`S(1)=7.4851` | 模型可拟合锚点，但尾部自由度不足 |
| Schnute | 端点精确，中间误差约 `-0.159/+0.197` | 两个形状参数仍不足以满足目标形状 |
| 端点锚定 Richards | SLSQP 出现奇异矩阵；TRF 稳定后仍约 `-0.251/+0.290` | 先修复优化器，再根据重复残差判断模型边界 |
| PCHIP | 可精确、单调、无过冲 | 因需求禁止分段而排除 |
| 全局四次 Bernstein | 四点达到机器精度，单调，1 个拐点 | 最终采用 |

## 关键经验

### 1. 渐近线不是有限端点

上渐近线为 10 不代表有限位置 `x=1` 自动接近 10。有限端点要求必须单独建模或验收。

### 2. 参数数量足够不代表一定可拟合

三个参数对应三个锚点只说明自由度数量相同，不保证目标点属于该曲线族。应利用解析变换、profile 方程或稳定重复残差判断可表达性。

### 3. 质量门禁必须逐点执行

不能只看 RMS。每个锚点都要输出 `prediction` 和 `residual`；任一点超限都不得生成 runtime。

### 4. 优化失败与模型失败必须分开

- `success=False`、奇异矩阵、参数触边：先修复参数化或优化算法；
- 多种稳定算法收敛到相同残差：再判断模型容量不足；
- 增加初值不能创造模型中不存在的解。

### 5. 尝试次数必须按完整回归计数

曾将 10 个窗口扩展为 `10×33×6=1980` 次回归，导致拟合卡死。兜底上限必须限制完整回归次数，而不是只限制外层循环。

### 6. 生成代码也要验收

Bernstein runtime 的各基函数项必须全部相加。拟合参数正确不代表复制出的 runtime 一定正确，应使用锚点进行 round-trip 校验。

## 最终模型

采用全局四次 Bernstein 多项式：

```text
S(x) = sum(c_i * B_i,4(x), i=0..4)
```

最终系数：

```text
[0.001, 3.0057589285714315, 3.244053571428568, 3.244053571428568, 10.0]
```

系数单调不减，因此曲线在 `[0,1]` 内单调且不会超出 `[0.001,10]`。四次多项式的二阶导数为二次函数，最多产生两个数学拐点。

拟合结果：

```text
predictions = [0.001, 3.9999999999999982, 5.999999999999999, 10.0]
max_anchor_error = 1.7763568394002505e-15
inflection_count = 1
```

## 求解方法

固定 `c_0=0.001`、`c_4=10` 后，两个中间锚点对 `c_1、c_2、c_3` 形成两个线性等式：

1. 使用 SVD 求特解和一维零空间方向；
2. 从 `c_0<=c_1<=c_2<=c_3<=c_4` 解析得到可行区间；
3. 在可行区间内最小化平均平方二阶导数；
4. 验证锚点误差、系数单调性、边界和拐点数量；
5. 输出 Bernstein 系数和纯标准库 runtime。

该过程只执行一次一维有界优化，不依赖多初值非线性回归。

## 验收清单

- 四个业务点的单点误差不超过 `1e-9`；
- 系数差值全部不小于 `-1e-12`；
- `S(1)>9.99`；
- 曲率零点不超过 2 个；
- runtime 中五项 Bernstein 基函数全部使用加法；
- runtime 对四个业务点的结果与离线预测一致；
